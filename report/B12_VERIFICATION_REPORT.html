🔍 验证方法：时间序列分析

核心思想： 不修改URDF，直接分析MuJoCo仿真中产生的时间序列数据来判断轴承好坏。轴承的质量直接表现在运动过程中产生的异常信号上。

数据来源

MuJoCo 仿真框架每 1/240 秒记录一次，共 6 秒仿真数据：

字段 单位 含义 例值
t 秒 时间戳 0.0 ~ 6.0
pen_max mm 该帧最大穿透深度 0.0095 (办公椅失败)
n_contact 个 该帧接触数量 54.8 (高接触频率)
stalled 0/1 是否停滞 (0=运动, 1=停止) 100% (完全锁定)

四个检测规则

📌 规则 1: 穿透深度检测

阈值： max_penetration > 0.005 mm

原理： 轴承设计好的情况下，零件应该被精确约束，不应该互相穿透。穿透 = 轴承刚度不足。

例子： 办公椅穿透 0.0095 mm → 超过阈值 → FAIL

📌 规则 2: 接触频率检测

阈值： mean_contact > 20 次/帧 或 max_contact > 40 次

原理： 轴承好的情况下应该平稳约束，而不是频繁碰撞。接触多 = 轴承无法保持稳定约束。

例子： 办公椅平均 54.8 次接触/帧 → 远超阈值 20 → FAIL

📌 规则 3: 停滞率检测

阈值： mean_stall_ratio > 0.05 (5%)

原理： 轴承好的情况下关节应该平稳运动，不应频繁卡住。停滞多 = 轴承摩擦过大或设计有问题。

例子： 风机 100% 停滞 → 关节被完全锁定 → FAIL

📌 规则 4: 综合判断

逻辑： if any_issue_found: score = 0.0 (fail)

原理： 轴承质量是"及格制"，只要有任何一个异常信号，就说明轴承有问题。

评分： 无问题 → score = 1.0 (pass) | 有问题 → score = 0.0 (fail)

⚠️ 问题分析

主要问题：假正例过多 (FP = 42)
42个案例被误判为失败，但人工标注为"满足"。这导致精度只有51.7%。

根本原因

时间序列方法采用严格的及格制阈值，对资产多样性不适应：

if max_penetration > 0.005 mm:      # ← 很严格（半微米）
    fail = True
if mean_contact > 20 per frame:     # ← 可能对不同资产类型不适用
    fail = True
if mean_stall_ratio > 0.05:         # ← 5% 停滞阈值
    fail = True
因素 Subset (10个) 完整训练集 (109个)
数据覆盖 10/10 (100%) 109/109 (100%)
案例多样性 低（可能有偏） 高（各种资产类型）
轴承基准 可能较一致 从微型到大型，基准差异大
准确率 90% 53.2%

结论

Subset的90%准确率是"幸存者偏差"：
这10个案例恰好符合时间序列阈值，但完整训练集的多样性超出了单一阈值的适用范围。
