# B11–B14 对照人工标注的校准结果

**结论先行:四条指标在 219 条人工标注案例上的判别力约等于零(AUC 0.49–0.57)。
问题不在阈值,也不在公式,而在测量对象——我们量的不是人在判的东西。**

本目录是这一结论的完整证据链与复现材料。

---

## 1. 数据集

人工标注来自 `articraft_annotation_v6/tools/569.csv`,569 条,最后四个维度
与 B11–B14 一一对应:

| 标注维度 | 指标 |
|---|---|
| 运动学关节的运动范围是否合理 | B11 |
| 活动零件是否具有可信的实体连接或支撑结构 | B12 |
| 运动过程中是否不存在非预期穿模或几何干涉 | B13 |
| 多部件机构的连接与运动关系是否合理 | B14 |

569 条不能全用。按来源分层后:

| 分层 | n | B11 | B12 | B13 | B14 |
|---|---|---|---|---|---|
| 新版原始标注 | 235 | 13/234 | 98/234 | 44/234 | 3/103 |
| 旧版350转换 | 334 | 0/316 | 62/334 | **0/0** | **0/0** |

(不满足 / 可判定数)

旧版转换的 334 条里 B13、B14 全部是"未核验",且转换置信度为中(272)或低(62),
其中 125 条明确标了"需要人工复核=是"。

**本研究采用的子集:219 条**(数据来源 = 新版原始标注,且 是否需要人工复核 = 否)

```
B12   不满足=92   满足=126      <- 42% 正例, 类别均衡, 主要分析对象
B13   不满足=41   满足=177      <- 19% 正例, 可用
B11   不满足=12   满足=206      <- 正例太少, 只能描述
B14   不满足= 3   满足=86  不涉及=130   <- 无法评估
```

## 2. 方法

```
model.py ──(articraft compile --target full)──> model.urdf + meshes
   └──> sim/loader ──> sim/primitives/sweep + sim/runner ──> signals
              └──> metrics/b11–b14 ──> score / prediction / sub_scores
                        └──> 与人工标签对照 (AUC / 混淆矩阵 / 逐因子)
```

- **重编**:219/219 成功,7.8 分钟,全部 `full` 级。零失败。
- **确定性已验证**:对一条已有 `full` 缓存的记录重编并 diff,`model.urdf` 与两个
  `.obj` **字节完全一致**;只有 `compile_elapsed_seconds` 与 `cache_key` 不同。
  即当前工具链(cadquery 2.7.0 / OCP 7.8.1.1)复现了当初的产出。
- **provenance 分布**:83 条 `asset`(URDF 带 `<inertial>`)、136 条 `inferred`
  (只有 `<collision>`,质量由 MuJoCo 按密度推)。这与静态扫描 `model.py` 预测的
  83 完全一致。
- **资产级聚合**:逐关节打分后取**最低分**,与人工标注的资产级粒度对齐。

### AUC 约定

正类 = 人工判"不满足"。

- `03_compare.py`:`AUC = P(score(不满足) < score(满足)) + 0.5·P(相等)`
  (分数越低越失败,故 1.0 = 完全分开)
- `06/07`:`AUC_high = P(特征(不满足) > 特征(满足)) + 0.5·P(相等)`
  (>0.5 = 值越大越失败,<0.5 = 反向,`|AUC−0.5|` 为信号强度)

两者都以 **0.5 = 纯噪声**为基准。

## 3. 结果

### 3.1 四条指标的判别力

| | 不满足 | 满足 | AUC | τ=0.70 平衡准确率 | 最优 τ 平衡准确率 |
|---|---|---|---|---|---|
| B11 | 11 | 186 | 0.566 | 0.503 | 0.624 |
| B12 | 92 | 126 | **0.490** | 0.508 | 0.527 |
| B13 | 41 | 177 | 0.552 | 0.575 | 0.607 |
| B14 | 3 | 86 | 未评估 | — | — |

B12 在 τ=0.70 下的混淆矩阵:`TP=92 FN=0 | TN=2 FP=124`——218 个资产判了 216 个
"不满足",是常数输出。

### 3.2 B12 为什么完全失效

```
分数恰好为 0 的比例:  不满足 58/92 (63%)    满足 83/126 (66%)
```

逐因子看:

| 因子 | AUC | 不满足 Q1/中位/Q3 | 满足 Q1/中位/Q3 |
|---|---|---|---|
| `f_anchor` | 0.568 | 0.141 / 0.371 / 0.696 | 0.183 / 0.558 / 0.799 |
| `f_g_drift` | 0.546 | 0.727 / 1.000 / 1 | 0.830 / 1 / 1 |
| **`s_clearance`** | **0.491** | **0 / 0 / 1** | **0 / 0 / 1** |
| `f_g0` | **0.471** | 0.177 / 0.918 / 1 | 0.106 / 0.843 / 1 |
| `S_payload` | 0.500 | 1 / 1 / 1 | 1 / 1 / 1 |

`s_clearance` 两组中位数都是 0。作为乘性因子,它一个人把 2/3 的 B12 分数清零。
`f_g0` 的方向是反的。

### 3.3 逐层排除

| 假设 | 检验 | 结论 |
|---|---|---|
| 阈值没校准 | 扫描最优 τ | 否。B12 最优 τ 也只到 0.527 |
| 公式毁掉了信号 | 直接看原始测量 | 否。`g0`/`g_drift`/`d_anchor`/`r_geom`/`s_clearance` 全部 AUC 0.44–0.52 |
| `g0` 用 min 太不敏感 | 保留每个几何到最近邻的完整分布,试 max/中位/超阈比例 | 否。最强 `j_frac_far_02` 仅 \|信号\| 0.089,**且方向相反** |
| 人在判"悬浮/脱离" | 同上 | 否。失败组几何**贴得更紧**(frac_far 中位 0.286 vs 0.481) |
| B12 标签只是整体质量的代理 | 对照 5 星评分 | 否。AUC 0.506;92 个失败案例里 88 个仍是 5 星 |

### 3.4 人的 B12 判断实际绑定在什么上

B12=不满足 与其他标注维度的共现:

| 维度 | B12不满足组 | B12满足组 | 提升 |
|---|---|---|---|
| **初始状态是否不存在非预期穿插、悬浮或脱离** | 42.4% | 11.1% | **+31.3pp** |
| 运动过程中是否不存在非预期穿模或几何干涉 | 27.2% | 12.7% | +14.5pp |
| 必要结构是否完整 | 19.6% | 6.3% | +13.2pp |
| 零件数量和种类是否符合描述 | 0.0% | 3.2% | −3.2pp |

`Notes` 列 219 条全为空,无自由文本可参考。

### 3.5 唯一有信号的方向

假设:人看的是**关节处有没有专门的连接硬件**(轴筒、销、支架),而非间隙大小。

| 特征 | AUC_high | \|信号\| | 不满足中位 | 满足中位 |
|---|---|---|---|---|
| `small_near_50`(关节轴 0.5·L_j 邻域内的小几何数) | 0.356 | **0.144** | **2** | **5.25** |
| `near_total_10` | 0.365 | 0.135 | 6 | 8 |
| `ngeom`(全资产几何数) | 0.398 | 0.102 | 25.5 | 32 |

前 18 名全部是同一族(关节邻域几何计数),AUC 0.356–0.393,**方向一致**——
不是单个特征碰巧。但 0.144 仍然太弱,单独做不了分类器。

## 4. 对规范的结论

1. **`S_clearance` 必须重定义或删除。** 规范只在 B12 公式里出现过这个符号,从未
   定义。当前任何"到第三方几何的净空"式定义在装配体里都会归零,而它是乘性因子。
   (对应 QUESTIONS.md #17)

2. **校准 τ 在 AUC≈0.5 时没有意义。** 建议搁置 #8,先解决测量对象问题。

3. **指标覆盖与真实失败分布错配。** 219 条里的失败分布:

   ```
   活动零件是否具有可信的实体连接或支撑结构   92   <- B12
   初始状态是否不存在非预期穿插、悬浮或脱离   53   <- 无任何指标覆盖
   运动过程中是否不存在非预期穿模或几何干涉   41   <- B13
   必要结构是否完整                        26   <- 无指标覆盖
   运动学关节的运动范围是否合理              12   <- B11
   多部件机构的连接与运动关系是否合理          3   <- B14
   ```

   B11 与 B14 合计对应 15 条失败,却占四条指标的一半;第二大失败模式(53 条)
   没有任何指标。

4. **`d_anchor` 的定义需要重新讨论。** 它是 B12 里 AUC 最高的因子(0.568),但
   规范只说"关节原点到接口几何中心的距离",未定义"接口几何中心"。
   (对应 QUESTIONS.md #16)

5. **人判的"可信实体连接"可能不是几何间隙能表达的量。** 唯一有信号的方向
   (关节邻域硬件存在性)不在规范的七个乘性因子里。

## 5. 已知局限

这些会影响结论强度,列出以便判断可信区间:

1. **契约从资产自身合成**(关节限位 → `expected_range`,每个关节 → 一个
   `expected_interface`)。真实契约应来自 prompt。后果:"该有的关节根本没声明"
   这类失败,验证器结构上看不见。**这是最重的一条局限。**
2. **B14 一条都没真正评估**——合成契约没有 `coupling`/`closed_loop`,89 条全部
   返回 `not-applicable`。表中 B14 的空白是方法学缺口,不是关于 B14 的结论。
3. **392 个关节的动态试验被截断**(每资产只跑行程最大的 3 个,且只跑 nominal 一次)。
   `S_gravity` 与 B13 的证据不完整。不过已跑部分的 `S_gravity` AUC 为 0.497。
4. **MuJoCo 对 mesh 碰撞体做凸包化**,空心资产的穿透量系统性失真
   (实测面包机 `p_dyn = 0.138 m`)。影响 `P_j` 与 `p_dyn`。
5. **219 条基本是一类目一条**,样本数 ≥3 的类目为 0,无法评估类目效应。
6. 人工标注本身未做双标注一致性检验。

## 6. 复现

scripts/03_compare.py             AUC / 混淆矩阵 / 逐因子判别力
scripts/04_disagreement.py        维度共现 + 分歧案例
