01 · 问题

我们真正要验证的是什么？

提示词 + 生成的关节式资产 → 可执行验证报告

生成系统可以从一句话产生 URDF、MJCF、model.py 或网格与关节。但“能解析、能加载、能在查看器里动”并不等于资产是正确机构。一把折叠椅、一个柜子或一件关节式工具可以有许多正确设计，若强迫与单一参考答案对齐，会把开放式生成问题错误地退化成重建。

现有评价为什么不够

  • 星级或 LLM 总评把多个独立失败压成一个主观数值，无法定位哪个关节、哪一帧、哪对连杆出错。
  • 解析器只能证明语法与图结构合法，不能证明抽屉有腔体、门有合页、轴周围存在真实间隙。
  • 仿真器会忠实执行已声明关节；它可以让没有合页几何的门绕一条虚拟轴转动。
  • 只比较一个参考答案会惩罚其他合理结构，无法处理一对多的设计空间。

本方案输出什么

  • 人类对齐向量：A1–A6、B7–B14 的分数、0/1/N/A、置信度与覆盖程度。
  • 工具原生诊断：语义、静态、运动、物理四类诊断与执行门。
  • 结构化失败报告：关节、帧、连杆对、原始数值、阈值和修复建议。
  • 可演化测试库：从人机分歧中积累可复现测试程序，而不是学习更讨巧的总分。
02 · 核心洞察

核心洞察：声明运动不等于可实现运动

声明的运动 ≠ 可实现的运动 URDF 中存在旋转/移动关节，只表示求解器被要求执行该自由度；它不能证明几何里真的存在合页、滑轨、接口、旋转间隙或承重支撑。

因此仿真器的正确角色不是替代几何验证，而是补齐时间、力、接触和多体耦合证据。B11–B14 的完整判断需要实际轨迹、接触冲量、动态穿透、重力漂移与同步误差；但 B12 的仿真成功仍必须乘上接口几何证据。形式上：

物理有效性 = 几何支撑 × 动态证据 仿真成功不能推翻几何反例

LLM / VLM

抽取显式契约、做部件语义匹配、评估多视角外观、提出新测试程序。不得读取工具摘要后再凭感觉给物理分。

几何 / FK / 碰撞

计算图结构、相对变换、轴线/原点、q₀ 完整性、接口间隙、局部净空、运动走廊与扫掠碰撞。

按指标路由的仿真器

只进入需要实际运动、接触力、重力、载荷或耦合轨迹的指标；记录参数来源与工具故障。

03 · 贡献

五项核心贡献

C1 · 基准

14项原子人类指标

不让标注员打模糊五星，而是对每个案例给 A1–B14 的 1/0/N/A。几何部件、声明运动学、实体可实现性与复杂物理彼此分工。

C2 · 可实现性

假关节的几何证伪

接口支撑、局部净空与扫掠碰撞联合识别“URDF 有关节、几何却没有机构”的核心失败。

C3 · 指标路由

按指标组合工具

语义问题交给契约/VLM，结构问题交给几何/FK，B11–B14 的完整覆盖引入固定协议仿真器。

C4 · 对齐

人类指标 ↔ 原子判据

逐项对齐而不是把14项硬塞进四类诊断；输出预测、覆盖程度、置信度、证据与修复建议。

C5 · 自演化

测试程序级演化

人类分歧触发新测试模板、触发条件和成功条件；评分公式、类别权重与留出集协议不演化。

04 · 统一架构

一条共享证据链，两类输出，一个冻结边界

输入

提示词（可选参考图）+ 生成的关节式资产 + 可选物理参数

▼

需求契约

显式部件 / 关节 / 功能 / 方向 / 耦合 / 安装；每条记录显式来源、先验与置信度。

可执行性门

解析、图结构、几何、FK 与碰撞查询；回答“能否评估”，不是第15项人类指标。

▼

共享证据引擎

结构与网格、32步 FK/扫掠、穿透、接口、净空、可达性、渲染、分时步动力学。

▼

人类指标对齐头

A1–B14：分数 / 预测 / 置信度 / 覆盖程度 / 证据。用于逐项人机一致性评估。

诊断头

执行门 + 语义/静态/运动/物理。用于基准评测、修复与测试程序记忆。

▼

分数 + 失败报告

不是一个黑箱标量：返回失败类型、关节、帧、连杆对、原始测量、阈值与修复建议。

▼

验证器自演化

只在开发集生长测试库；评测前记忆、触发条件、阈值与公式冻结。

可选设计器修复

在冻结验证器上选择确定性修复算子；人类与自动双轨评测防止奖励投机。

输入规范化器

统一单位、坐标系、可视/碰撞网格与物理参数来源；不静默修复资产。

聚合器 + 报告

N/A 不补0、不补满分；分数必须与人类指标覆盖程度、仿真覆盖程度同时报告。

演化控制器

只让经过 k≥3、全14项回归和人工审核的可执行检查进入下一版测试库。

留出集上发现的新失败不能在当前实验里回填。它只能进入下一版本待办。否则系统等于用测试集改评分器，任何“自演化提升”都失去可信度。
06 · 两阶段演化

先演化验证器，再冻结它改进设计器

阶段1 · 验证器

在500例上逐项比较人类标签 y_i 与自动预测 ŷ_i。覆盖漏洞通过修正触发条件/阈值处理；缺失测试由 LLM 提议可执行程序。准入后形成带来源记录的测试程序记忆。

阶段2 · 设计器

冻结验证器。设计器读取结构化失败报告，按执行门 → 可实现性 → 语义 → 功能 → 物理的顺序派发挖腔、加滑轨、移轴线等算子。

评测

两者均冻结，在1,500例留出集上运行。人类与自动结果必须同时报告；若自动分数上升而人类分数不升，就是奖励投机信号。

07 · 评测

主要结果、消融与诚实边界

主结果

  1. 人类–人类 κ，作为每项可达到一致性的参照。
  2. 人类–自动逐项精确率、召回率、F1、平衡准确率与 κ。
  3. 置信度阈值–覆盖程度的选择性风险曲线。
  4. 人类总分与自动 Score_full 的 Spearman，而不是要求数值相等。
  5. 已见与未见类别的泛化差距。
  6. 修复后目标判据与人类标签是否同时失败→通过。

关键消融

  • 去掉几何可实现性：B12/B13 明显崩塌。
  • 去掉仿真器：B11–B14 只能得到部分覆盖。
  • 去掉契约：语义与功能目标无法定义，大量 N/A。
  • 去掉测试程序记忆：长尾/未见类别 F1 下降。
  • 只调阈值、不新增测试：新失败模式无法解决。
  • 不冻结验证器：自动分数虚高，人类分数可能不升。
局限影响报告方式
契约抽取抽错会同时影响多个语义/功能项抽样人工核对，记录来源/置信度，先验不直接扣分
碰撞网格质量会影响穿透、扫掠与净空输出几何来源与网格覆盖程度
物理参数来源默认质量/摩擦的结论不等于真实物理资产自带/推断/默认分档，降低置信度
人类判断歧义A4/B12 的 κ 可能较低把人类–人类一致性作为自动验证上界参照
奖励投机设计器可能贴着阈值优化人类/自动双轨、阈值聚集审计、高分人工对抗抽检
